# برنامج مبيعات المكتبة - نسخة تأسيسية

## المتطلبات
- Flutter SDK حديث
- Android Studio أو أدوات Android SDK
- هاتف أندرويد أو محاكي

## التشغيل
1. فك الضغط.
2. افتح مجلد المشروع في Android Studio أو الطرفية.
3. نفّذ:
   flutter pub get
   flutter run

## ما الموجود؟
- قاعدة بيانات SQLite محلية.
- إضافة الأصناف والأسعار والرصيد الافتتاحي.
- بحث بالاسم أو الباركود.
- تسجيل حركة الرصيد الافتتاحي.
- خدمة لإنشاء فواتير بيع ومشتريات ومرتجعات ضمن معاملة قاعدة بيانات.
- منع بيع كمية أكبر من المخزون.
- سجل حركات المخزون، وتعديل الجرد.
- ملخص مبسط للمبيعات والمشتريات والمرتجعات.

## ملاحظات مهمة
هذه نسخة تأسيسية قابلة للتشغيل وليست برنامجًا محاسبيًا جاهزًا للاستخدام التجاري بعد.
- شاشة البيع والمشتريات والمرتجعات وربطها بالواجهة لم تكتمل بعد.
- طباعة PDF A4 والنسخ الاحتياطي الفعلي واستعادة النسخة والصلاحيات تحتاج إلى استكمال واختبار.
- منطق أرصدة العملاء والموردين والمدفوعات يحتاج إلى دفتر حسابات متوازن قبل الاعتماد المالي.
- نسخ قاعدة البيانات مباشرة أثناء الكتابة قد ينتج نسخة غير متسقة؛ استخدم آلية تصدير متوافقة مع SQLite عند استكمال النسخ الاحتياطي.
- قاعدة البيانات إصدارها 1؛ عند تعديل الجداول مستقبلًا أضف migrations ولا تحذف قاعدة المستخدم.
